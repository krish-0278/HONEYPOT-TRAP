Honeypot Deception Architecture

1. System Architecture

Honeypot Security System operates on an isolated deception grid. Malicious requests arriving at deceptive endpoints are evaluated through risk heuristics, categorized, logged into tamper-resistant forensic files and SQL records, and served realistic decoy responses.

2. Risk Calculation Matrix

• SQL Injection (Risk 5): Triggers on SQL union, syntax escapes, and boolean logic (' OR 1=1). Intercepted and routed to the fake database dump trap.
• Automation Tools (Risk 5): Detected via User-Agent inspection (sqlmap, cURL, python, postman, empty agents). Routed to the simulated server terminal.
• Cross-Site Scripting (Risk 4): Intercepts script tags, image error triggers, and javascript URIs.
• Brute Force & Bot Speed (Risk 3-4): Flags rapid requests under 500ms or 3+ failures within 20 seconds.

3. SOC Integration

The SOC Console provides enterprise operators with real-time incident triage, MITRE ATT&CK alignment, IP forensic lookup, and automated executive report generation with CSV download.
